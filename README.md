# Roxy Accesorios – control de tienda

1. Supabase: crea un proyecto. En SQL Editor pega y ejecuta `supabase.sql`.
2. Settings > API: copia URL y anon key a `.env.local` (ver `.env.example`).
3. Local: `npm install && npm run dev`. Código de acceso: 1209 (se cambia en `CODE`, `app/page.js`).
4. Vercel: sube el repo, agrega las dos variables de entorno y despliega.

No hay cuentas de usuario: el código solo abre la pantalla. La base de datos queda abierta a quien tenga la URL y la anon key.
